# Allocation Temperature in Reservoir Computing

Reproducibility package for **Allocation Temperature in Reservoir Computing: Structural Paths, Safe Regions, and Test-Time Sensitivity**.

**Author:** Ildefons Magrans de Abril  
**Affiliation:** Universitat Politècnica de Catalunya - BarcelonaTech (UPC)

## Neural Networks submission freeze

The repository is frozen at manuscript **v19.5**, the Elsevier `elsarticle` submission version prepared for *Neural Networks*. The scientific evidence is unchanged from the v19.0 executable-evidence reset; v19.1-v19.5 contain journal-fit, disclosure, reviewer-preemption, administrative, and Elsevier-formatting changes only.

The exact flat Editorial Manager source is retained under `submission_v19_5/`. A self-contained copy of the same source is under `manuscript/`, with the eight submission figures stored beside `main.tex`. The submitted PDF is identified by SHA-256 in `SUBMISSION_FREEZE.md`.

## Submission evidence policy

Every M19-M21 numerical claim used by the submission is generated by the current executable protocol. Archived development-era numerical summaries remain under `results/frozen/` for history only and are not used by the submission layer.

M23, SRP04b, and SRP05 retain their original full executed analyses.
