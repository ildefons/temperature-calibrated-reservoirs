# Temperature-Calibrated Reservoirs - Overleaf Project (v19.0)

Main file: `main.tex`

This project is self-contained for Overleaf upload. It uses a manual `thebibliography` block inside `main.tex`, so BibTeX/Biber is not required. `references.bib` is included as a convenience reference file.

Recommended Overleaf settings:
- Compiler: pdfLaTeX
- Main document: `main.tex`

Submission author: Ildefons Magrans de Abril, Universitat Politecnica de Catalunya - BarcelonaTech (UPC), Barcelona, Spain, ildefons.magrans@upc.edu.

## Version 19.0

Version 19.0 is the executable-evidence reset. Every M19-M21 number used by the submission is generated by the current frozen protocol and stored under `results/reproduced/` in the public repository. The two real-data benchmarks use four deterministic chronological splits and the official UCI datasets. M23, SRP04b, and SRP05 remain unchanged and retain their original executed analyses.

See `CHANGELOG_V19.md` for the detailed changes.
